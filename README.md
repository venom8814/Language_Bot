## Запуск в PyCharm

### 1. Клонируй / распакуй проект
Распакуй архив в удобную папку.

### 2. Открой в PyCharm
File → Open → выбери папку `language_bot`

### 3. Создай виртуальное окружение (рекомендуется)
```
Python 3.10+
```
PyCharm → Settings → Project → Python Interpreter → Add → Virtualenv

### 4. Установи зависимости
Открой терминал в PyCharm:
```bash
pip install -r requirements.txt
```

### 5. Запусти
```bash
python main.py
```
